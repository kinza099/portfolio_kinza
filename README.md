## 🚀 How to View & Deploy

### Quick Local Preview
- Double-click `index.html` in your file explorer to open it in any web browser.
- Or run: `python -m http.server 8000` and visit `http://localhost:8000`.

### Deploying to GitHub Pages (Free)
1. Create a repository on [github.com/new](https://github.com/new) named `portfolio` (set to **Public**).
2. Click **"uploading an existing file"** and drag all files from `portfolio_kinza` (`index.html`, `README.md`, `css/`, `js/`).
3. Click **Commit changes**.
4. Go to **Settings** > **Pages** > under **Branch** choose `main` > click **Save**.
5. Your site will be live at `https://<your-username>.github.io/portfolio/`!
